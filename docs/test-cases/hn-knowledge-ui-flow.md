## 老编辑页保存发布链路

原页面保存流程为：取上传地址 → PUT 正文 → 写草稿/发布。基础服务新增兼容网关 `/api/knowledge-legacy/:baseId/**`：

- 目录、正文、草稿读取、新建文档复用知识服务数据，按知识库做权限校验。
- 上传地址回到基础服务并附带 HMAC 短时效票据（10 分钟，绑定 baseId 与 key），浏览器跨端口 PUT 无需会话；伪造票据返回 401。
- 允许 `contenttype` 预检头：老编辑页发送的是空值 `contenttype`（非标准拼写），否则浏览器预检失败并报 “Failed to fetch”。
- 发布（`boss/helpdoc/menu/save`）在知识服务内写正文、清空草稿并入队派生；老页面的旧同步入口 `POST /api/knowledge-base/sync-from-doc-platform` 改为兼容应答，不读写数据。
- 正文读取地址按随机 capability key 直读，等价于 OSS 预签名读。
