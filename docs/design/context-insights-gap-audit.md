## 结论摘要

- **约定的 11 行功能映射**（`context-insights-migration.md`）：全部有实现；其中 3 行是"部分"——Current Context 缺压缩预留段、Context Browser 技能未单列类别、File Activity 缺图片与操作日志展开。
- 本轮再补齐 4 项：步骤摘要三行（`Point.brief`，服务端批量取正文并截断）、事件 Token 净变化（压缩前后请求估算差）、搜索结果按命中文件归因（解析 `tool.success` 的 `content`）、附件清单（`Analysis.attachments`，仅描述不含字节）；时长曲线（durationCurve）也已实现。
- 附件筛选与文件预览跳转已实现：文件活动内的文件路径可打开现有 `FilePreviewDialog`（沙箱未运行时对话框内显示错误态，属环境限制）；附件单独作为筛选项。
- **原项目 README 的完整能力集**：仍缺 1 项——Live 下一个请求预览。它需要调用 `SessionModelRequest.prepare` 组合"尚未发送"的请求，而 prepare 会触发 session hooks 并分配标识，旁路调用有副作用风险；未做旁路，避免污染真实执行状态。
- 明确不做的 3 项：Prune/计划模式事件（SaaS 无对应事件）、overviewAutoSteps（无该概念）、图像 Token 估算与附件预览（不保留字节）。
- **本仓库额外具备、原项目没有**：PG 多 Pod 无状态、网关侧逐会话授权与家族裁剪、服务端派生总览 scope、压缩修正常规化为独立请求、UTC 结算归因口径声明。
