```
└──────────────┘                 └───────────────────────┘
        │                                  ↑
        │        Agent（会话/外部 MCP）─────┘
        └── 挂载 unified-search / wiki-search / book-open MCP 工具

  流转：
  1) 写内容 → 跳 hn-docs 编辑 → publish → upsert 任务 → hn-app 任务中心可见
  2) 调知识 → hn-app 召回测试 / Agent 检索工具 → hn-knowledge 检索
  3) 看引用 → 来源引用卡片（两边字段一致）→ 深链回 hn-docs 原文/块
  4) 管治理 → hn-app 看索引状态、lint、图谱溯源；发现问题跳 hn-docs 修正
```

## 12. 状态与空态（统一规范）

```
  加载：骨架屏（列表/卡片/三栏各自骨架），不闪白
  空态：图标 + 一句话说明 + 主行动按钮（如"上传第一篇文档"）
  失败：错误原因 + [重试] + [查看详情]；任务失败可逐条重试
  索引中：🔄 徽标 + 进度（文档级）；整库顶部横幅显示整体进度
  降级：hn-knowledge 不可达 → 顶部横幅"知识服务暂不可用，展示缓存目录"（同连接器板块模式）
  危险操作：删除知识库 → 二次确认 + 影响面清单（文档/分块/向量/任务将删除）
```
